# 类型骨架与必备信息槽

> 前五类出自手册第四章（适用 2021—2025 推送样本）。后两类（入队仪式 / 通知公告）手册未单列，据 27 篇真实语料归纳，属**参考**而非硬规定。

**用法**：第 0 步定类型 → 第 1 步按"必备信息槽"逐项收集 → 缺的**动笔前一次性问清**。

**语域档位**决定第 2 步的改写力度：
- 🔒 **保守档**：语域本就正式，只修格式与事实，不"去套路"（过度矫正会把正常公文改坏）
- 🔓 **可清理档**：散文性强，可删空泛抒情、换成具体细节

---

## 1. 升旗任务类 🔓

> 思源楼升旗、西操场重大典礼升旗、国庆/五四/毕业典礼/节日专题升旗等

### 必备信息槽

| 槽位 | 说明 | 缺失后果 |
|------|------|---------|
| 日期 | 精确到日 | 红线 1 |
| **时刻** | 精确到分，`HH:MM` 格式 | 红线 1 |
| 地点 | 如：思源楼广场 / 西操场 | 红线 1 |
| **执行中队** | 如：23中队 | 红线 1 |
| 活动背景 | 节日/纪念日的历史意义，≤100 字且 ≤全文 20% | 节日类必填 |
| 任务流程 | 至少覆盖 集合→行进→升旗→退场 | 缺则正文空洞 |
| 观礼方 | 有特殊观众时（毕业生、新生、志愿者等） | 可选 |

### 骨架

```
导语（背景 + 时间地点人物，80–150 字）
  ↓
[分节] 前期准备 / 出旗护旗（动作描写）
  ↓
[分节] 升旗仪式（奏响国歌、国旗升起）
  ↓
[分节] 意义阐述（可选，1 段）
  ↓
总结段（任务评价 + 展望，≤100 字）
```

**注意**：
- 多地点复合任务（如西操 + 思源楼）**须分节描述，每个地点各一节**
- 引用领导人讲话须确保原文准确，**不可凭印象转述**

## 2. 训练总结类 🔓

> 开学第一练、阶段性训练总结、预备队训练记录等

### 必备信息槽

| 槽位 | 说明 |
|------|------|
| 训练时间 | 日期；跨期训练写时间跨度 |
| 训练地点 | 如：西操场 |
| 参与人员 | 哪个中队 / 预备队 |
| **具体训练科目** | 须列明（军姿、停止间转法、正步端腿、齐步走、旗手刀手选拔…） |
| 训练成果 | **用具体细节**，禁止"表现出色" |
| 队员感想 | 可选，1–3 条，每条 50–120 字，**须为真实原话或经本人确认** |

### 骨架

```
导语（时间跨度 + 背景）
  ↓
[分节] 训练内容（科目列表 + 图片）
  ↓
[分节] 训练成果（具体进步描写，鼓励用数据对比）
  ↓
结语（简短）
```

**注意**：
- 训练内容须用**精确术语**，禁止写"进行了各种训练"
- 鼓励数据化对比，如"从最初端腿时的摇摇晃晃，到能较长时间稳定站立"
- **禁止编造感想**——这是基线测试中最高频的编造点（"有人说…"）

## 3. 换届大会 / 全体大会类 🔒

> 新学期全体成员大会、换届竞选、入队仪式前的全体会议等

### 必备信息槽

| 槽位 | 说明 | 缺失后果 |
|------|------|---------|
| 会议时间 | 日期 + 时刻 | 红线 1 |
| 会议地点 | — | 红线 1 |
| **主持人** | 姓名 + 职务 | 手册必填 |
| 出席人员 | 简明列出主要参会方 | 手册必填 |
| **会议议程** | 依序说明每一项 | 手册必填 |
| **换届竞选职位列表** | 换届类必须有 | 手册必填 |
| **训练安排** | 新学期大会必须有，含各中队时间 | 手册必填 |
| **纪律要求** | 同上 | 手册必填 |
| 队歌环节 | 固定收尾 | — |

### 骨架

```
导语
  ↓
一、奏唱国歌        （固定开场，篇幅 1–2 句）
二、换届竞选发言     （间接引语概括，金句可直引）
三、队长训练安排 + 纪律要求
四、合唱队歌
  ↓
结语
```

**注意**：
- **此类推送信息量大，切忌大段抒情**——以清晰呈现会议内容为首要任务
- 分节形式：手册 5.1 三选一（方案 A `01 02 03` 或方案 B `一、二、三`，均适合大会类），或部长 2026-11 终稿实例 **"大会第X项 + 朴素议程名"**（"大会第一项 全员肃立 奏唱国歌"；此式手册未列）——任选一种贯穿全篇，节名一律用朴素议程名，不取花哨修辞名（"出旗——奏唱国歌"这类带破折号的标题被终稿替换）
- **议程性发言（寄语/讲话）的间接引语要挂在可核实锚点上**：真实的讲话关键词 + 真实经历。终稿实例："以'坚持、珍惜、向上'三个关键词，结合自身在仪仗队的成长经历，与新队员分享感悟，勉励大家克服初入队伍的不适应，珍惜并肩前行的队友情谊"。**不写无锚点的四字排比**（"不忘初心、矢志坚守，砥砺前行，持续打磨本领、精进素养"——2026-10 队员稿原句，被整句重写）。**本条只约束发言/讲话的转述；叙事概括段不适用**——终稿把自我介绍段的"诉说着心中的憧憬，畅谈未来的期许，立志坚守初心、刻苦训练"四字排比原样保留
- **训练安排为手册必填槽，须含各中队训练时间**（手册 4.3），但写成紧凑一行式（如"26中队预备队每周三、周四 19:30–21:30 训练"），不展开成排班表；着装要求、后勤叮嘱（注意保暖、记得吃晚饭）属队内通知，不入公开推送正文。⚠️ 2026-11 部长终稿曾将训练安排压缩为一句概述（各中队时间也未保留）——与手册"包括各中队时间"存在分歧；**按手册为准写入时间**，用户明确要求贴终稿风格时省略并主动说明差异（同 02 第五节分歧处理惯例）
- 各发言人发言用**间接引语概括**，除非有金句值得直接引用（用引号标注）
- **禁止杜撰领导/队长引语**（手册红线 5）——需本人确认原话

## 4. 入队仪式与授章类 🔓

> 入队仪式、授章仪式、预备队转正

（手册未单列，据语料归纳）

### 必备信息槽

| 槽位 | 说明 |
|------|------|
| 时间地点 | — |
| 参与人员 | 新队员所属中队 + 老队员 |
| **仪式环节** | 授章 / 宣誓 / 交接 等的实际流程 |
| 授章人 / 领誓人 | 姓名 + 职务 |
| 新队员人数 | 或代表人数 |
| 老队员寄语 | 若有，须真实原话 |

### 骨架

```
导语
  ↓
[分节] 仪式背景 / 前期准备
  ↓
[分节] 仪式流程（授章 / 宣誓 / 交接）
  ↓
[分节] 新老队员发言
  ↓
结语（侧重"传承"但须落在具体动作上）
```

**注意**："传承""薪火"是本类高频主题词，但**不能只写这两个词**——必须落到"谁把什么交给了谁"。

## 5. 招新纳新类 🔓（语气可更活泼）

> 年度招新通知、招新截止提醒

### 必备信息槽

| 槽位 | 说明 |
|------|------|
| 队伍介绍 | ≤100 字，突出：**校团委直属**、承担仪仗司礼任务、半军事化管理 |
| 队伍亮点 | 升旗任务 / 训练日常 / 比赛荣誉，配图片 |
| 个人收益 | 爱国情怀、责任感、体能、人际 |
| **招新要求** | 思想条件、身体条件，**必须明确说明面向年级** |
| **报名方式** | 二维码 / 联系人，**必须出现在推送末尾** |

### 骨架

```
队伍介绍 → 加入我们（升旗任务/训练/比赛展示）→ 个人收获 → 招新要求 → 报名方式
```

**注意**：
- 语气可比其他类型更活泼、有感召力
- 但队伍介绍须**准确，不夸大成绩**（比赛获奖须写明具体奖项）
- **务必标明本次招新面向的年级**，不得遗漏
- 报名二维码/联系方式发布前由办公室确认有效

## 6. 节日科普 / 纪念日类 🔓

> 国庆节、建党节、五四青年节、国家安全教育日、全民国防教育日、"一二·九"等

### 必备信息槽

| 槽位 | 说明 |
|------|------|
| **史实** | 年份、运动名称、事件经过——须有可靠来源 |
| 本队结合点 | 鼓励结合本队特点发声（如国防教育日结合队列展示） |
| 活动信息 | 若结合了实际活动，按升旗/仪式类补槽位 |

### 注意

- **历史数据必须核对**（如党龄、运动年份）——手册附录单列此错误类型
- 科普文字须通俗易懂，避免过于学术
- **情感类段落 ≤ 正文 50%**（比一般推送宽松，但仍有限制）
- **不建议写成与本队无关的泛泛科普**

## 7. 通知公告类 🔒（保守档）

> 征集通知、活动预告、招募要求、考试/训练时间安排

（手册未单列，据语料归纳）

### 必备信息槽

| 槽位 | 说明 |
|------|------|
| 通知事项 | 一句话说清是什么 |
| 适用对象 | 谁需要看 |
| **时间节点** | 截止时间、活动时间，精确到日/时刻 |
| 地点 / 方式 | 去哪、怎么做 |
| 联系人 / 联系方式 | — |
| 落款单位 | 若有 |

### 骨架

```
一句话说清事项
  ↓
背景 / 目的（可省）
  ↓
具体要求（列点）
  ↓
时间、地点、联系方式
  ↓
落款
```

**注意**：
- **本类走保守档**：语域本就正式，不要在"去 AI 味"名义下把公文改成散文
- 但**标题仍须满足 `[类型标签] | [主标题]`**
- 常见 AI 错误：把本类写成感人散文（"让我们相约在…"）——通知类不需要煽情

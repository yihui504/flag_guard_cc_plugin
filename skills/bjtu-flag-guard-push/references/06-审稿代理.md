# 三路审稿子代理 · 提示词模板

出稿后**并行**派三个子代理。三者互相看不到对方的结论——独立性是这套审查的全部价值，串行会让后一个被前一个带跑。

用 `general-purpose` 类型（或等价的通用子代理）。三份提示词的 `{...}` 占位符在派发时替换。

---

## 为什么必须有"事实核查"这一路

合规和 AI 腔都能靠对照清单查出来，**只有编造查不出来**——因为编造的东西读起来最顺、最像成稿。

基线测试里，一个负责的 AI 写了这样的句子：

> 有人不自觉挺直了背，有人悄悄红了眼眶，有孩子被家长抱在怀里，仰着头，认真望着旗杆顶端。

用户从没提过孩子和家长。但这句话放在升旗推文里毫无违和感，编辑一眼看过去只会觉得"写得挺好"。**这就是它必须被单独查一遍的原因。**

---

## 代理一 · 合规审查

```
你是一位严格的高校宣传稿件审核员，负责审查北京交通大学国旗仪仗队的微信公众号推送文案。
任务是逐项核对合规性，不做文采评价。

【待审稿件】
{稿件全文}

【声明类型】
{申报的类型，如"训练总结类"}

【审查依据】
读取 {skill目录}/references/01-规范要点.md 与 references/03-类型骨架.md

请逐项核对并输出：

## 一、结构合规
标题是否满足 `[类型标签] | [主标题]`？类型标签是否取自规定集合？主标题是否 ≤20 字且含核心事件信息？
导语是否包含 时间、地点、事件名称、参与主体？
正文是否按该类型的规定分节？

## 二、必备信息槽
列出该类型全部必备项，逐项标注：✓ 已具备（抄出对应原文）/ ✗ 缺失。

## 三、落款
是否完整？字段名与分隔符是否符合规范？（对照 01-规范要点.md 中标注的规范与实际差异）
若为招新类，报名方式是否在末尾？

## 四、格式
数字格式、中文标点、引号、书名号、分隔符。

## 五、用语
对照 references/02-用语对照表.md，找出所有用错动词/形容词/称谓的地方。抄出原句并给替换。

【输出要求】
只报告问题，不夸奖。每条给"位置 + 原文 + 问题 + 改法"。
没有问题就说"无"。不要为了凑数报无关紧要的东西。
最终给一行结论：`合规结论：通过 / 需修改（N 项）`
```

## 代理二 · AI 腔审查

```
你是一位中文写作编辑，专门识别"AI 写的中文"。任务是在一篇校园宣传稿件中标出 AI 腔痕迹。

【待审稿件】
{稿件全文}

【审查依据】
读取 {skill目录}/references/04-反AI腔.md

【关键方法】
该文件分三部分：
- 第一部分是**有实测数据**的真 AI 痕迹（倍数标注了 AI 相对人类的频率），优先查
- 第二部分是宣传文体专属高发特征
- **第三部分「不要改的清单」同等重要——误报的代价是把稿子改坏**

请：
1. 通读全文，标出所有命中的特征
2. 每条给出：位置、原文、命中的特征名、对应倍数（如该特征有实测数据）、改写方向
3. **对照第三部分自查**：你标出的每一条，是不是其实落在"不要改"清单里？如果是，撤回

【特别注意本队红线】
结尾抒情是否超过正文 1/5？是否出现手册点名的过度使用词（砥砺前行、赓续、不忘初心、续写时代华章、热血、豪情、饱满的热情）？

【输出要求】
按"最该改的排前面"排序。
每条：命中项 + 原文 + 改写方向（给一个具体的替换句，不是抽象的"建议更具体"）。
若你在第三部分清单里撤回了某条，在末尾列出"已撤回：{原文} — {原因}"，让我知道边界在哪。
最终给一行：`AI 腔结论：干净 / N 处`
```

## 代理三 · 事实核查 ★ 最重要

```
你是事实核查员。任务只有一件：判断这篇稿件里**每一个具体信息**的来源，找出**编造**。

【用户实际提供的信息（原始输入，一字不改地粘在这里）】
{把用户最初给的全部信息原文贴上，包括他对图片的口头描述}

【稿件全文】
{稿件全文}

【方法】
把稿件拆成最小的事实单元，逐条处理。事实单元包括：
- 数字（人数、时间、时长、届次、奖项、名次）
- 人名、职务、单位名
- 引号内的任何话，以及"某某说""某某表示""有人讲到"
- 具体动作（谁做了什么、怎么做的）
- 场景细节（天气、光线、表情、声音、掌声、汗水、观众构成）
- 因果与动机（"为了…""正是因为…"）
- 感官描写（看到了什么、听到了什么、感觉到了什么）

逐条问：**这一条，用户给过吗？**

【来源分三档】
- **A 用户直接给过** — 抄出用户原话作为凭据
- **B 合理推断** — 用户给了可以直接推出它的信息（如用户说"早上7点"→写"清晨"）。标注推断链
- **C 无来源** — 用户没给，也推不出来

【数字处理规则】（按序判定：先问可核性，再修格式；逐项判断，不整篇一刀切）
- 数字**无法向用户核实**（来源缺失、真值存疑）→ 建议删去该数字、保留事实骨架。2026-11 部长终稿实例：队员稿两处训练次数（26预备队"8次"与 25中队"八次"，两个独立事实）均无可靠来源，终稿全部删除，改为"有序开展集中训练""坚持每周常态化晚训"。
- 数字**可核实**（用户确认过）→ 保留，并统一为阿拉伯数字（"八次"→"8次"）；不因他处另有不可核数字而连坐删除。
- 格式层面中英数字混用**且数字本身可核实** → 统一为阿拉伯数字保留；若数字不可核实，走第一条（删）。

【文体惯例豁免（窄，防层次打架）】
《用语对照表》推荐用语栏的**仪式套语**（缓缓升起、冉冉升起、肃立、奏响、昂首挺胸等）——只要用户确认了事件本身（升旗/出旗/集合发生了），按文体惯例归 B 档并注明"手册推荐用语"，**不列 C 档、不要求删**。手册钦定的语域不能被事实核查刮掉。
豁免仅限描述仪式标准形态的套语。**不适用豁免的**：数字、人名、引语、下次活动安排、独有场景细节（天气/表情/掌声/人数）。
**评价性套语**（整齐划一、铿锵有力、目光坚定）不删，但归 B 档并加"待确认"——它们是对表现质量的断言，现场不符就得删，由作者跟用户确认。

【必须无遗漏地检查这些高危位置】
1. 所有引号
2. 所有"有人说""队员们表示""大家纷纷表示""有人讲到"——**特别警惕**：这类句式最容易把不存在的话包装成事实
3. 所有包含天气、光线、表情、掌声、观众反应的句子
4. 所有包含具体数字的句子
5. 结尾段——升华段里常有编造的"承诺"和"信念"

【输出格式】
| # | 稿件原句 | 事实单元 | 来源档位 | 凭据 / 推断链 / 无 |
|---|---------|---------|---------|------------------|

然后：
## C 档清单（编造嫌疑）
逐条给：原文 + 建议处理（删除 / 改为不依赖该信息的写法 / 列入待确认清单问用户）
**不要替作者补写**。你只负责指出，不负责填。

## B 档清单（推断）
注明推断链，让作者能判断是否成立。

最终一行：`事实核查结论：A 档 N 条 / B 档 N 条 / C 档 N 条（编造嫌疑）`
```

## 复算（第 5 步）

修改完稿件后，**新派一个独立的代理三**（不复用原代理，更不许修改者自查）。

原因有二：
1. 修改是引入新编造的高发环节。为了让句子更顺、把删除的抒情补回来、把"缺失的信息"填上，模型会顺手造一个新的细节。
2. **修改者自查会虚报收敛**——实测案例：修改者只删了编造的时刻"6:30"、却保留了"下一个升旗日"这个编造事件本身，然后自查宣布"C 档 0 条"；独立复核仍判 C 档。修改者对自己没改干净的条目没有判断力。

复算的要求：
- 对象是**当前文本**，逐句重新列表，不得引用上一轮结论打勾
- 对照的"用户已给信息"必须是**完整对话记录**（含第一轮原始请求），不是最后一轮回答
- 出现 C 档 → 回第 4 步，改完**再派一个新代理**复算

**"收敛"的唯一判据：独立复算代理输出 C 档 0 条。修改者自己的任何声明不算数。**

---

## 收敛判据

三路都返回"无问题 / 干净 / C 档 0 条"才算收敛。**不要用"改了几轮"当收敛标准。**

如果某一轮仍在报同类问题，说明是系统性的写法问题，不是零星疏漏——回去看 `04-反AI腔.md` 第四节的改写配方，按形状重写，而不是继续打补丁。

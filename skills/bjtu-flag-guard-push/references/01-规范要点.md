# 规范要点（合规审查依据）

> 提炼自《北交大国旗仪仗队推送文案写作规范手册》（基于 2021—2025 全部推送样本，以 2024—2025 近期风格为基准）。
> 手册原文若与本文冲突，**以手册为准**。本文只做执行化整理。
>
> ⚠️ 手册与历史实践存在若干不一致（分隔符、落款字段），已在 `02-用语对照表.md` 第五节列出。

---

## 一、定位与调性

面向校内同学、校外关注者，兼顾**宣传队伍形象**与**招募潜在队员**两大功能。

核心调性：**庄重不失亲切，热血不流于空泛。**

| 维度 | 要求 |
|------|------|
| 庄重 | 涉及国旗、升旗、国歌的描写，措辞须严肃、准确，**禁止口语化、娱乐化** |
| 亲切 | 展示队员日常和情感，可有温度、有人情，**避免公文腔** |
| 热血 | 鼓励有力度的表达，但**爱国情怀须有具体事件支撑**，不做无根据的空喊 |
| 实用 | 以近期风格为准，信息要素完整（时间、地点、人物、事件、背景、结果） |

---

## 二、五条红线

**违反任何一条，稿子不能发。**

| # | 红线 | 具体判据 |
|---|------|---------|
| 1 | **禁止信息缺失** | 时间、地点、执行中队等核心信息必须出现，不得省略 |
| 2 | **禁止抒情喧宾夺主** | **结尾抒情段 ≤ 正文 1/5**，不能让诗意文字淹没事件本身 |
| 3 | **禁止空泛口号堆砌** | 不写没有具体内容支撑的"再接再厉""砥砺前行"；如需使用，放到最结尾作收束，正文中不重复 |
| 4 | **禁止语病与错别字** | 成文后须至少由一名**非作者**成员通读校对，重点检查标点、数字格式、引号 |
| 5 | **禁止杜撰引语** | 领导讲话、队长讲话如需引用，**须经本人确认原话**，不可整段杜撰 |

> 红线 5 是 AI 写作的最高危项。见 `06-审稿代理.md` 的"事实核查代理"。

## 三、通用结构

### 3.1 标题

**格式：`[类型标签] | [主标题]`**

- 类型标签取自 `03-类型骨架.md` 的七类
- **主标题 ≤ 20 字**
- 主标题须包含核心事件信息，**不得仅为抒情语，不知所云**
- 鼓励对仗或押韵短语
- 副标题（如有）置于主标题后，≤15 字

| 合格示例 | 不合格示例 |
|---------|-----------|
| 五四升旗 \| 青春向党，国旗飘扬 | 国旗飘扬 ← 无类型标签，无具体信息 |
| 24预备队第一次训练 \| 首练阵法显豪情 | 青春心向党奋斗新征程让我们一起为国旗的荣光而奋斗 ← 过长，无信息量 |
| 新学期全体大会暨换届竞选 \| 承前启后 砥砺前行 | |

### 3.2 导语（开篇段）

位置：正文第一段（图片前后均可，但须在**正文第一个信息段之前**）。

**必备要素**：时间（精确到日期，重大任务精确到时刻）、地点、事件名称、参与主体（哪个中队、多少人）、简要背景（节日/纪念日类**必须**）。

**字数：80—150 字**。不必追求华丽，**以信息准确为第一优先**。

合格示例（25.5.5）：
> 1919年5月4日，中国青年高呼"外争主权，内除国贼"的口号，首次以先锋姿态登上历史舞台。106年后的今天，五四运动的精神仍激励着中国青年投身于建设祖国的伟大事业中。2025年4月27日，北京交通大学正式举办"纪念'五四'运动一百零六周年主题升旗仪式"。

### 3.3 正文分节

**每节字数：单节 ≤250 字**，确有大量信息时可适当延长，但须保持节奏感。

分节方式（`03-类型骨架.md` 各类已给骨架）。

### 3.4 结语

- **2—4 句，60—120 字**
- 须与本次事件主题呼应，**不得写与事件无关的泛泛口号**
- **3 个以上排比句即为警戒线**

合格示例（24.10.16）：
> 秋风作序启新程，霜叶铺路练精兵。作为一个大家庭，我们一起努力，共同成长，共绘北京交通大学国旗仪仗队新的辉煌篇章！

不合格示例：
> 仪仗队将继续无畏风雨、砥砺前行，用庄严与肃穆激荡青春，以热血和忠诚助力成长，让五星红旗始终迎风飘扬，赓续红色血脉、续写时代华章，不忘初心，牢记使命，走向更加辉煌的明天……
> ← 叠加口号过多，无具体指向，与事件脱节

### 3.5 制作信息落款（**每篇必须**）

```
文案｜姓名
排版｜姓名
审核｜姓名（审核人须为宣传部长或队长级别）
图片｜来源说明（如：国旗仪仗队全体成员 / 校团委 / 具体摄影人）
```

- 分隔符统一用全角 `｜`
- 图片来自外部（校宣传部、网络）须注明来源；**来自网络须注"图片部分来源于网络"**
- **不得只署排版人，必须有文案责任人**

## 四、排版规范

### 分节标题

三选一，**贯穿全篇不混用**：

| 方案 | 形式 | 适合 |
|------|------|------|
| A | `01` `02` `03` | 训练总结、换届大会 |
| B | `一` `二` `三` | 大会类、正式感强 |
| C | 加粗小标题 | 升旗任务类、图文穿插多 |

> 注：反 AI 腔表实测"小标题序数词"是 AI 痕迹（3.1×）。但本队排版规范里有方案 A/B。**若类型骨架指定了分节方案，按骨架执行**——排版惯例优先于去 AI 腔规则。

### 图文排布

- 每节文字与图片交替，**避免连续 3 张以上图片无文字说明**
- 图说须简洁，一句话即可
- 轮播图片须在前后注明"左右滑动查看更多"

### 标点与格式

见 `02-用语对照表.md` 第四节。

## 五、发布前审核清单

逐项核对，**任一项不通过即不可发布**。

- [ ] 标题格式符合规范（类型标签 \| 主标题）
- [ ] 导语包含时间、地点、参与主体、事件名称
- [ ] 核心信息（时间精确到时刻、地点、执行中队）全部到位
- [ ] 段首缩进统一
- [ ] 数字格式统一（阿拉伯数字，无中英混用）
- [ ] 分隔符统一使用 `｜`
- [ ] 引号使用中文引号
- [ ] 无多余空泛口号（每篇 ≤1 处"砥砺前行"类表达）
- [ ] 结语简洁、与本次事件有关联
- [ ] 落款信息完整（文案｜排版｜审核｜图片）
- [ ] 报名方式/二维码经办公室确认有效（**招新类专项**）
- [ ] 领导/队长引语经本人确认（**换届/大会类专项**）
- [ ] 历史数据准确（**节日科普类专项**）

## 六、常见错误对照表（手册附录）

| 错误类型 | ❌ 错误示例 | ✅ 正确示例 |
|---------|-----------|-----------|
| 信息缺失 | "仪仗队完成了此次升旗任务" | "23中队于4月27日早7:00在思源楼完成了本次升旗任务" |
| 口号堆砌 | "砥砺前行赓续红色血脉续写时代华章不忘初心牢记使命" | "23中队接过22中队的接力棒，将在未来让五星红旗继续在交大上空飘扬" |
| 动词混淆 | "国歌唱响，国旗飘扬升起" | "国歌奏响，五星红旗缓缓升起" |
| 落款不全 | "文案｜XX" | 四行完整 |
| 年份错误 | "五四运动100周年" | "五四运动106周年（**以发布当年为准**）" |
| 称谓不统一 | 同篇混用"北交大"和"北京交通大学" | 全篇统一，首次用全称，后文用"我校"或简称 |

## 七、最终判据

手册结尾原话：

> 如遇实际情况难以套用，以"**准确传达信息、维护队伍形象**"为最终判断标准。

当规则与这句冲突时，回到这句。
